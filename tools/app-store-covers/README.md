# Ascendr App Store Covers

This folder contains the static source used to compose Ascendr's six iOS App Store screenshot covers.

Run `node tools/app-store-covers/serve.mjs`, then open `http://127.0.0.1:4179/?cover=scan`.
Replace `scan` with `nutrition`, `home`, `workouts`, `coach`, or `progress` to preview the other covers.

The final 1290 x 2796 PNG exports are in `public/media/app-store-covers`.
